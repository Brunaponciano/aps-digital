# 🏥 APS Digital

> Plataforma digital para facilitar o acesso dos pacientes aos serviços da Atenção Primária à Saúde e melhorar a comunicação entre pacientes e UBS.

🚧 **Status: Projeto em desenvolvimento**

---

## 🎯 Sobre o projeto

O **APS Digital** é um projeto de tecnologia inspirado em necessidades observadas no cotidiano da Atenção Primária à Saúde.

A proposta é utilizar a tecnologia para facilitar o acesso dos pacientes aos serviços da UBS, reduzir dificuldades no agendamento e melhorar a organização das informações.

A primeira versão do projeto será composta por **dois sistemas principais**:

- 📱 Aplicativo do paciente
- 💻 Sistema Web da UBS

O aplicativo para Agentes Comunitários de Saúde será desenvolvido futuramente, como uma expansão do projeto.

---

## 📱 Aplicativo do paciente

O aplicativo permitirá que o paciente tenha acesso a serviços e informações da UBS de forma mais prática.

### Funcionalidades planejadas

- 🔐 Login e identificação do paciente
- 📅 Agendamento de consultas
- 🔄 Remarcação de consultas
- ❌ Cancelamento de consultas
- 👨‍⚕️ Escolha de profissional/especialidade
- 💉 Carteira de vacinação
- 🔔 Alertas de vacinação
- 💊 Informações sobre medicamentos
- 📦 Histórico de retiradas
- 📋 Informações sobre renovação de receitas
- 🔔 Notificações sobre renovação de receitas

---

## 💻 Sistema Web da UBS

O sistema Web será destinado aos profissionais da UBS para auxiliar na organização dos atendimentos e agendamentos.

### Funcionalidades planejadas

- 🔐 Login de profissionais
- 📅 Gestão de agendas
- 👥 Gestão de pacientes
- 🩺 Organização das consultas
- 👨‍⚕️ Cadastro e gestão de profissionais
- 📋 Visualização dos agendamentos
- 🔄 Gerenciamento de remarcações e cancelamentos
- 📊 Organização das informações para atendimento

---

## 👩🏽‍⚕️ Futuras versões

O módulo destinado aos Agentes Comunitários de Saúde será desenvolvido posteriormente.
